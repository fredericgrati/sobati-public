# Public Sobati information site

Static, deliberately minimal content intended for publication at
`https://public.sobati.fr` through GitHub Pages. It contains no link, address,
inventory, credential, or operational information about the private Sobati
infrastructure.

Publication is intentionally separate from the private server migration. It
requires a chosen GitHub repository and the DNS CNAME/verification details
provided by GitHub Pages; no Alfred/Sobati server change is involved.
